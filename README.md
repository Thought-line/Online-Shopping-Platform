# Online Shopping Platform
Implement product management for OSP-3
## Project Overview
Online Shopping Platform is a sample software project designed to manage products, customers, shopping carts, and orders. This repository is used to test GitHub and Jira integration with PulseCheck.

## Features
- Product Management
- Shopping Cart Management
- Order Tracking
- Payment Processing
- Bug Fixing and Issue Tracking

## Technologies
- Frontend: HTML, CSS, JavaScript
- Version Control: Git and GitHub
- Project Management: Jira
- Project Health Monitoring: PulseCheck

## Development Workflow
1. Create a Jira issue for each development task.
2. Create a GitHub branch using the Jira issue key.
3. Commit code changes with the Jira issue key in the commit message.
4. Create a pull request and include the Jira issue key in its title.
5. Track development activity through the GitHub–Jira integration.

## Jira Integration Example
Jira Issue: SHOP-1

Example branch:
`SHOP-1-product-management`

Example commit:
`SHOP-1 Add product management feature`

Example pull request:
`SHOP-1 Implement product management`

Replace `SHOP-1` with the actual issue key generated by your Jira project.

## Purpose
This repository helps test the integration between GitHub and Jira and supports the development of automatic project mapping and project health metrics in PulseCheck.
