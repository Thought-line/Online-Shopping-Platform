# Online Shopping Platform

## Project Overview
Online Shopping Platform is a sample software project designed to manage products, customers, shopping carts, and orders. This repository is also used to test GitHub and Jira integration with PulseCheck.

## Planned Features
- Product management
- Shopping cart management
- Order tracking
- Payment processing
- Bug and issue tracking

## Technologies
- Frontend: HTML, CSS, JavaScript
- Version control: Git and GitHub
- Project management: Jira
- Project health monitoring: PulseCheck

## Development Workflow
1. Create a Jira issue for each development task.
2. Create a GitHub branch using the Jira issue key.
3. Commit changes with the Jira issue key in the commit message.
4. Open a pull request and include the Jira issue key in its title.
5. Track development activity through the GitHub–Jira integration.
